## Deploy the full page

The complete single-file `index.html` (~230 KB) was built in chat. The GitHub API tool has a payload limit, so upload the full file once:

1. Download `index.html` from the chat artifacts.
2. On GitHub: open this repo → **Add file** → **Upload files** → drop `index.html` → commit to `main`.

Or from your machine:

```bash
git clone https://github.com/himanshubamotrawork-gif/gravyy.git
cd gravyy
# put the full index.html in this folder, then:
git add index.html
git commit -m "Add full GravyPass landing page"
git push
```

## GitHub Pages

**Settings** → **Pages** → Source: **Deploy from a branch** → Branch: `main` / root → Save.
